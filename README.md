# calculator-project

A simple calculator built using HTML, CSS, and JavaScript.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the calculator in your browser.
2. Enter numbers and operators.
3. Click "=" to get the result.
